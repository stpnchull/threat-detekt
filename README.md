# Threat Detekt


Threat Detekt is a custom-trained computer vision system designed for real-time security monitoring and early threat identification. The model detects people and identifies whether they are in possession of potentially dangerous weapons, including pistols, rifles, shotguns, and knives.

The system is designed to support low-latency inference across multiple deployment architectures. It can operate as a centralized inference service that processes live or near-real-time image streams, or as an embedded inference application running directly on edge computing hardware such as the NVIDIA Jetson Orin NX.

Threat Detekt is intended to provide an extensible foundation for security-focused applications where rapid detection, classification, and association of a person with a potentially lethal weapon can be used to generate downstream alerts, events, or additional automated analysis.
